# nooodL — GitHub Pages demo

This folder is ready to publish as a static GitHub Pages site.

## What is included
- `index.html` — homepage
- `learning.html` — learning philosophy page
- `assets/` — only the images, logo files, and videos actually used by these pages
- `.nojekyll` — tells GitHub Pages to serve the files as a plain static site

## Fastest deployment
1. Create a new GitHub repository, for example `nooodl-demo`.
2. Upload **the contents of this folder** to the root of the repository (do not upload the outer folder itself).
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/(root)`, then save.
7. GitHub will publish the site at a URL similar to:
   `https://YOUR-USERNAME.github.io/nooodl-demo/`

The homepage must remain named `index.html`.
